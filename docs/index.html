⚔️ Uncompromising Security

Engineered for Cryptographic Autonomy

Explore eight flagship capabilities designed to eliminate threat vectors inherent in cloud-based credential managers.

🚨

Duress Password & Decoy Vault

Under physical coercion, enter a secondary duress password at the unlock screen. Kryptx immediately provisions a realistic decoy vault while keeping your real master database cryptographically invisible.

📄

Vector PDF Emergency Kit

Generate an offline, printable 1-page vector recovery kit complete with handwriting boxes, master custody instructions, and an encrypted QR key for secure deposit box storage.

📎

Encrypted Documents & Keyfiles

Attach passport scans, private `.pem` SSH keys, and encrypted photo documents directly to any credential entry with AES-256-GCM sandbox isolation.

🔑

Real-Time TOTP 2FA Authenticator

Built-in RFC 6238 two-factor code generator with smooth 30-second countdown rings, SHA-1/256/512 algorithms, and instant QR camera ingestion.

📡

Zero-Cloud Local P2P Vault Sync

Directly beam encrypted vaults between nearby Android devices via local Wi-Fi or hotspot using ephemeral AES-256 session keys and 6-digit PIN handshakes.

📷

Offline CameraX QR Scanner

Process 2FA TOTP barcodes and peer-to-peer sync keys entirely in volatile device memory without persistent cache writes or external dependencies.

🛡️

Runtime Anti-Tamper Protection

Real-time security hooks scan `/proc/self/maps` for Frida, Xposed, Substrate injection, active debuggers, su/magisk binaries, and test-keys.

🗂️

11 Multi-Category Records

Store logins, payment cards with Luhn verification, secure notes, identities, crypto seed phrases, Wi-Fi credentials, API tokens, and server keys.
